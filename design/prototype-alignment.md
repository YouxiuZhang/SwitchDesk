# 0.2.5 原型对齐标准

依据是用户当前打开的 `http://localhost:60966/` 原型，而不是另起一套设计。2026-10-17 从浏览器 DOM 保存到 `reference-prototype.html`；`prototype-reference.png` 为当前窄面板视口的原型截图。

已确认的偏差：Windows 原来是顶部 TabControl、原生下拉和独立大预览；Mac 原来是两块独立的大白卡、过大的标题和空白，缺少原型设备卡及独立剪贴板导航。

本次还原：

- 左侧 188px 导航：控制台、剪贴板与文件、设置。品牌紫色底图标，浅灰侧栏。
- 色值：正文 `#242933`，次级文字 `#7b818d`，边线 `#e7e9ee`，主色 `#6554d9`，页面 `#fbfcfd`，侧栏 `#f6f7f9`。
- 单张淡紫色主卡 `#f1effb` / `#e4dff5`，圆角约 15。左侧当前控制、目标、切换与快捷键，右侧约 238px 宽监视器内真实预览；支持放大。
- 下方为“我的设备”双卡、键鼠来源双选项卡、共享剪贴板和真实传输面板。
- 设置整理为配对/连接、显示器设置、快捷键与预览等卡片；保留各平台实际需要的权限与校准操作。
- 使用平台原生窗口边框，不在 Windows 伪造 Mac 红黄绿窗口按钮。

行为约束：不修改后端切屏/恢复/输入/配对/传输实现；不将原型中的假设备在线、假传输、假桌面或未实现的开机启动/改快捷键开关带入产品。保留具体错误与独立恢复 Windows 入口。没有网卡类型证据时不声称 Wi-Fi/以太网。

核验使用真实 Mac 视图的隔离模式，避免启动第二个真实会话或访问用户配对密钥/剪贴板。截图中的未连接状态须如实标注。Windows 此环境仅能交叉编译，不能把 Mac 截图当作 Windows 真机验证。
