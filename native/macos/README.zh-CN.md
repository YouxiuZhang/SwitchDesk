# 双栖 SwitchDesk 0.2.10 · 浅银图标版

Mac：Apple 芯片（M1/M2/M3/M4 等），macOS 13 或更新版本。
Windows：64 位 Windows 10/11，.NET Framework 4.8 或更新版本。
两台电脑各用一根视频线连接同一台显示器，并连接同一局域网；Windows 有线、Mac Wi-Fi 可以混用。本次 Mac 与 Windows 均升级到 0.2.8，提供独立的恢复 Windows 入口。Windows 完成显示器确认后，也可像旧 0.1.0 一样独立切屏，不依赖 Mac 联网或键鼠权限。

## 安装与连接

1. Mac 解压 ZIP，把“双栖.app”拖到“应用程序”，从应用程序打开。Windows 先退出旧版双栖（包括托盘），运行新版 EXE 安装程序。
2. Windows“设置”中选择 AOC 显示器、Mac 所接的 HDMI 1 / HDMI 2 / DP。若已确认看到 Mac 桌面并返回 Windows，可直接勾选“我看到 Mac 画面，并已切回 Windows”；程序只读取当前输入，核对成功就保存。还没看到 Mac 桌面时，先点击“安全试切并自动返回”。此步骤只在初次配置或更换接线时需要。
3. Windows“设置 → 显示邀请并复制 → 导出文件”，把 `.switchdesk` 文件传到 Mac；Mac“设置 → 打开邀请文件…”导入。也可以复制 `switchdesk1:` 字符串并粘贴。首次连接在 Windows 点击允许。
4. 仅切换显示器可先点击控制台按钮，不要求键鼠或录屏权限。若需要键鼠共享，Mac“设置”分别查看辅助功能和输入监听，点击“申请键鼠权限”按系统提示授权。两项都授权后点击“刷新检测”；需要共享 Mac 画面时，另行点击“申请录屏权限”。系统要求重启应用时，退出双栖后重新打开。
5. 两端选择键鼠来源，点击切换按钮或按 F12 切换（Mac 顶排默认调音量时按 Fn + F12）。首次配对、断线重连或紧急恢复后，点击来源设备重新启用键鼠。

Windows 防火墙如提示，允许双栖在自己的专用网络通信。Windows 服务端端口为 TCP 45923；不需要开放公网端口。若有 VPN 或多张网卡，邀请中使用的 Windows 地址必须能被 Mac 访问。

## 日常使用

- 键鼠来源可以选 Windows USB 接收器的键鼠，也可以选 Mac 键盘与触控板；切换画面不会改变来源。
- Ctrl + Alt/Option + Esc 紧急收回键鼠，并请求恢复操作所在电脑画面。连接中断也会释放输入。Windows UAC、安全桌面和高权限程序不保证能被普通权限进程控制。
- 两端开启共享剪贴板后同步**新复制**的文字和图片。复制文件或文件夹后，在另一端 Finder / 资源管理器粘贴，才开始下载；完成校验后交付文件。可从应用内取消。
- 文件清单最多 4096 项、总计 16 GiB；文字最多 1 MiB、PNG 最多 8 MiB。Mac 原生文件粘贴等待最多 75 秒，大文件或慢网络可能超时，可取消后重试。
- Windows“设置”开启“允许 Mac 查看本机屏幕预览”，控制台开启“显示另一台预览”。Mac 开启“另一台桌面预览”并授予录屏权限。预览约 5 帧/秒，窗口关闭、无订阅、锁屏或连接断开会暂停；无有效画面会显示暂停状态。
- 关闭窗口后应用继续在菜单栏 / 托盘运行；选择“退出”才结束。不会自行设置开机启动。
- 邀请包含连接密钥，只交给自己的 Mac。连接使用 TLS 和证书指纹校验；Windows 可以撤销配对。

## 本版验证范围

用户已确认 Windows 0.1.0 能切换实际显示器。本版沿用该 DDC 执行器，由 Windows 统一控制显示器输入；Mac 通过局域网发指令，因此不依赖 Mac 转接器是否能传递 DDC。HDMI、USB-C 转 HDMI、USB-C 转 DP 的最终可用性仍取决于显卡、转接器和显示器。

本版完成两端编译、Mac 界面启动检查、TLS 会话与错误证书拒绝测试、文件分块/校验/取消测试。Windows 原生运行、双机键鼠、Finder ↔ 资源管理器粘贴和切源后的预览仍需双机实测，不能将交叉编译视为这些功能已验收。

Mac 应用为本地临时签名，尚未 Apple 公证；Windows 安装程序尚无发布者签名。若系统阻止打开，请使用系统提供的单应用审核入口确认本包来源，不要关闭全局安全防护。

0.2.2 修复：分开“显示器可切换”和“键鼠可共享”条件；重连不再保留已断开提示；预览未开启时指明 Windows 设置开关。未获得键鼠权限时输入始终留在本机；Mac 全局快捷键仍需输入监听权限，未授权时用按钮切换。1 秒黑屏目标仍未实测达标。

0.2.3 修复：画面确认不再被自动试切结果锁住。用户主动勾选后只回读当前 Windows 输入；读取失败或显示器选择变更时不保存并显示原因，不会再次写入切屏命令。

0.2.4 恢复流程：若切到 Mac 后显示“尚未确认”，点击“恢复 Windows 画面”。此操作只尝试回到之前已确认的 Windows 接口，并在 Windows 检查显示器身份和当前输入；不会自动启用远程键鼠。切换时权限变化或重连不会再让状态一直卡在切换中。程序重启后，发现保存的显示器且读到任一已知接口即可恢复配置，不必在 Mac 画面时重新勾选。若显示器无法被 Windows 枚举或读取，仍需显示器信号源菜单恢复，软件不会宣称成功。

0.2.5 界面调整：按已确认原型统一侧栏、淡紫切换主卡、嵌入式屏幕预览、设备卡、键鼠来源卡与剪贴板卡；控制台、剪贴板与文件、设置三个入口。所有在线状态、预览和传输仍来自真实设备，不使用原型演示数据。保留 0.2.4 的独立恢复 Windows 流程。

0.2.5 恢复补充：安全试切前，读取并保留 Windows 返回接口；即使尚未勾选“看到 Mac 画面”，也能从 Mac 请求恢复 Windows。试切期间的恢复请求会通知原守护进程返回，不重复写入。恢复成功不会代替你的 Mac 画面确认。尚无返回地址、操作正在进行或前次进程尚未退出时，会显示具体原因。两端必须一起升级并退出旧进程；Mac 设置页可核对双方版本。

## 0.2.6：切屏状态与键鼠就绪

- 切屏只发送一次写入。瞬时回读失败或仍返回旧接口时，按 250ms 间隔最多读三次；读取成功立即结束。900ms 是重试调度预算，不是驱动调用或黑屏时长上限。
- 原先已完成显示器确认、切屏写入成功但回读未确认时，控制台提供“AOC 已显示 Mac/Windows，确认画面”。只在外接 AOC 确实显示该桌面后点击，应用里的预览不算；该入口有效两分钟，断线、改选显示器或下一次切屏后失效。确认后选择键鼠来源，权限仍必须齐全。
- Mac“设置”分别显示辅助功能、输入监听和事件钩子状态；键鼠授权与录屏授权分开。若授权后仍未就绪，按系统提示退出重开双栖，再刷新检测。建议只保留并运行“应用程序”中的同一份双栖。
- 控制台显示最近一次命令、查找显示器、预读、写入与回读的耗时。它们不等于面板黑屏时间。本版没有实测证明黑屏达到 1 秒，双机键鼠仍需实机验收。

## 0.2.7：恢复后自动同步按钮

切屏写入已成功但立即回读失败时，Windows 会在后台按 0.5、1、2 秒的间隔最多再做三次只读核对，不再次发送切屏命令。读到 Windows 接口后，双方自动显示 Windows，主按钮变成“切换到 Mac”。输入保持未启用，来源选择仍检查权限。后台结果会核对操作和显示器映射，旧操作不能覆盖新状态。

如果这些读取仍失败，界面保留“待确认”和已有的明确画面确认入口，不把未确认的恢复当作成功。0.2.5 没有这项自动同步，须退出旧版后更新；可以在 Mac 设置页核对双方版本。

## 0.2.8：F12 切换与 Windows 绘制修复

- 两端全局切换键统一为 F12，长按只切换一次，松开再按才再次切换。原 Ctrl + Alt/Option + Space 不再切换；Ctrl + Alt/Option + Esc 紧急恢复保持不变。应用在托盘/菜单栏运行时仍监听。
- Mac 全局 F12 依赖辅助功能和输入监听授权；若 F12 默认是音量键，使用 Fn + F12，或在系统键盘设置中将顶排设为标准功能键。不会拦截音量按键。
- Windows 修复自绘按钮背景未重绘造成的重复文字、黑角与残影，并调整高 DPI 描边边界和滚动页宽度。

## 0.2.10：浅银图标与桌面入口

两端统一使用浅银双窗口图标。Windows 程序、任务栏、托盘、安装器与应用内品牌图标已接入，安装和升级主流程自动创建桌面快捷方式。先从托盘退出旧进程，再安装新版；原配对和显示器设置保留。Windows 包包含 0.2.9 的鼠标位移合并修复。Mac 包只调整品牌视觉，不修改输入或切屏逻辑。Mac 使用临时签名，替换后如系统要求重新授权，请在辅助功能和输入监听中确认新应用。
