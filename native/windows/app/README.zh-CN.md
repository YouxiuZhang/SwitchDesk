# 双栖 SwitchDesk 0.1.0 切屏测试版

在 Windows 上双击安装程序，安装后打开“双栖”。无需运行脚本，也不需要安装开发工具。

## 使用

1. Mac 和 Windows 各接一根视频线到同一台显示器的不同输入口，两台电脑均保持开机。
2. 打开双栖，选择这台显示器，以及 Mac 所接的输入口。接口名称可以看视频线插口旁的标记。程序不会猜测 Mac 接在哪个口。
3. 点击“试切到 Mac”。程序会在倒计时后尝试切回原输入；显示器或视频链路拒绝命令时，恢复仍可能失败。
4. 返回 Windows 后，只有确实看到过 Mac 桌面并已切回，才确认试验成功。随后可以使用窗口按钮或 Windows 键盘的 Ctrl+Alt+Space 切换，Ctrl+Alt+Backspace 尝试返回 Windows。

切换未确认或没有画面时，可用显示器的信号源按钮选择原来的输入口。AOC 27G2 的信号源列表包含 HDMI1、HDMI2 和 DP；菜单确认后等待画面恢复。不要拔掉视频线作为正常切换方式。

## 本版范围

本版测试的是显示器画面切换。键鼠仍控制原来连接的电脑，键鼠共享、复制粘贴共享、另一台电脑的实时预览尚未接入。Mac 键盘目前不能触发 Windows 端快捷键。

程序不会自动改刷新率，不设置开机启动，不上传测试记录。可以在窗口中导出记录后发给开发者。关闭窗口会退出；正在进行的首次试切会由独立恢复进程完成已有的一次切回尝试。

这是尚未做发布签名的测试包；编译与核心逻辑已验证，Windows 实机安装和显示器写入效果仍需测试。若系统阻止运行，请保留提示反馈，不需要关闭系统保护。

## 安装和卸载

面向 Windows 10/11 64 位，需要 .NET Framework 4.8 或更新版本。安装程序会检查，不会静默下载依赖。安装在当前用户目录，无需管理员权限。

可从 Windows 应用列表或开始菜单“双栖 SwitchDesk → 卸载”移除。卸载只移除程序文件和自己的快捷方式，保留用户已导出的测试记录。
