# Windows 切屏安装测试版验证

版本：0.1.0。交付入口：`dist/installer/SwitchDesk-Setup-0.1.0.exe`。

这是带原生界面的显示器切源测试版。通过 VCP 0x60 控制所选显示器输入，首次试切有独立进程尝试恢复。键鼠共享、剪贴板共享和实时预览尚未实现。

## 构建环境

- macOS Apple Silicon；未使用 Windows 虚拟机或 Wine。
- 项目内 PowerShell 7.6.6 所带 Roslyn；编译语言 C# 5。
- 微软 NuGet `Microsoft.NETFramework.ReferenceAssemblies.net48` 1.0.3 引用程序集；不将 .NET Core 程序集混入 Windows 应用。
- NSIS 3.04 macOS 编译器来自 electron-builder-binaries 的 `nsis-3.0.4.1` 官方维护版本，下载后 SHA-512 与该发布页公布值一致。
- 工具仅放在 `.build/tools`，没有全局安装 SDK，也没有改用户执行策略。

构建命令见项目 README；应用、配置和中文说明打入当前用户安装程序。安装无需管理员，创建开始菜单、可选桌面快捷方式及卸载入口，检查 .NET Framework 4.8 与 Windows 10/11 x64。没有网络服务或开机自启。

## 自动验证

- 完整现有测试运行：62 项，55 通过，7 项 Windows 专属集成测试因当前平台跳过，用时39.011秒。包括新增的5项状态规则测试。
- 补齐无效映射负向用例后，针对应用重新运行6项核心测试，全部通过（4.965秒）。测试覆盖试切门禁、往返及画面确认、输入候选限制、忙碌状态、取消确认与映射失效；不代替硬件测试。
- 交叉编译成功；PE 元数据为 AMD64、Windows GUI 子系统、CLR v4.0.30319、版本0.1.0.0。引用均为 .NET Framework 4.0.0.0 系列程序集，含 WinForms；嵌入 asInvoker 清单。
- NSIS 安装程序成功编译；修复卸载命令引号后无编译警告。
- 解包安装程序，程序、配置、说明三份文件与构建输出逐字节一致；7-Zip 完整性检查通过。应用为64位PE，NSIS安装器及卸载器为兼容64位Windows的32位PE。

## 保护与审查范围

工作进程隔离原生调用、限制等待并确认退出；无法确认退出时停止后续写入。首次试切由独立 guardian 串行执行目标操作与恢复，GUI 退出后已有恢复任务继续。新开的 GUI 和安装器识别现有工作进程，避免重叠操作或替换仍在执行的程序。只有回读到原输入并由用户确认看见过 Mac 桌面，才启用普通切换。

输入口候选值为 HDMI1=17、HDMI2=18、DP=15；并未证明任意显示器或转接链路均接受这些命令。原输入来自实际回读，不预设17。设备变化清除映射确认。

## 未验证事项

本机不能运行 Windows GUI、安装/卸载过程或调用 Windows DDC。因此真实窗口显示、系统热键、用户设备上的双向切源、回切时长以及非当前输入仍能接受 DDC 的行为均待 Windows 实机测试；没有声称通过。安装包未做发布签名。

历史 Windows 报告中的18次输入17回读来自未切换连接的场景，只证明当时读取成功，不证明双向切屏。
