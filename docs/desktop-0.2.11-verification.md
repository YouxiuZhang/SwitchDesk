# Mac 0.2.11 窗口收回验证（2026-10-25）

## 变更

仅更新 Mac（0.2.11 / build 12），兼容 Windows 0.2.10，协议不变。

确认切到 Windows 后，后台将单一外接屏上的普通 Mac 窗口收回内屏；确认回到 Mac 后，恢复仍处于程序放置位置的窗口。用户移动/缩放过的窗口保持原样。设置中的“自动收回 Mac 窗口”默认开启，需辅助功能权限。

不改变扩展/镜像模式、分辨率、主屏设置、DDC 时序、键鼠来源。全屏、最小化、隐藏应用、不可移动窗口和不明确的屏幕组合跳过。窗口几何信息只保存在内存中，不读取标题或内容。

独立 utility 队列执行 AX 消息，每次 AX 请求超时 100ms；扫描不重叠，每轮使用 1.5 秒软预算。断线、未知状态、正在切屏、权限失效、显示器排列变化会取消旧任务。Mac 目标下恢复等待最多 15 秒，之后保留当前位置。
