# 双栖浅银图标与 Windows 桌面入口

用户反馈 Windows 没有桌面图标，并要求重新设计更有质感的应用图标。已展示深石墨方案，用户选择“更轻盈的浅银色”。定稿方向为珍珠白底座、相扣的银灰双窗口、少量冷蓝反光。使用 imagegen 内置工具生成；透明边缘须干净，缩小后符号可辨认。

Windows 缺少桌面入口的原因：快捷方式创建在安装完成页的可选回调里；应用未嵌入 ICO，窗口和托盘使用默认系统图标。修复后安装/升级主流程创建桌面快捷方式，EXE、安装器、卸载器、窗口、任务栏、托盘、应用侧栏采用同一图标。快捷方式指向固定安装目录内的 EXE，不指向临时安装包。

Mac Dock/访达采用相同 ICNS，应用侧栏使用同一 PNG。菜单栏保持适应明暗模式的简化单色双窗口轮廓。只调整品牌图标，不改已确认的页面布局、功能、配对和输入处理。

两端发行版本统一为 0.2.10。在隔离输出目录构建和核验，先交付安装包；不直接覆盖用户正在使用且已授权的 Mac 进程。本地临时签名不能保证替换后系统权限自动延续。

验证：透明 PNG、16–256 多尺寸 ICO、16–1024 ICNS 内容检查；Windows EXE 实际包含 RT_ICON/RT_GROUP_ICON；安装包完整性及载荷匹配；Mac 优化构建和严格签名验证；运行现有产品回归。Windows 桌面/任务栏显示仍需真实 Windows 安装验证，不以交叉编译代替。
